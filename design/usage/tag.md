# Tag — usage card

Status: standing · 2026-10-31
Parent: [INDEX.md](INDEX.md)
Read when: screen work draws this component. Build or change: spec leaf instead.

- Purpose: Short status label, not tappable.
- Use when: Tone: Critical overdue · Warning due soon · Success paid · Info new · Neutral plain status. Icon on for Critical when it must read at a glance.
- Don't use: anything tappable — instead Chip or Button; a message with a reason or next step — instead Notice. (added 2026-11-04, design-critic round 1)
- Content rules: One line, 2-3 words. "Overdue 7 days".
- Behaviour: display only, no tap.
- A11y: label 12 medium, every tone 7.22:1 or more.
- RTL: icon leading; set Typography mode ar to flip (RTL row).
- Related: Chip, Payment card
