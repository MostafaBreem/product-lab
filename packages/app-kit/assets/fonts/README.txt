Bawazek Sans + Bawazek Sans Arabic (2026-10-31)

What: IBM Plex Sans 1.1.0 (8 upright weights) and IBM Plex Sans Arabic 1.1.0 (8 weights), renamed because the SIL OFL 1.1 Reserved Font Name "Plex" may not be used by modified fonts. Added: Saudi riyal sign U+20C1 (SAMA 2025 design) taken from Saudi Riyal Font 1.1.0 (Emran Alhaddad, SIL OFL 1.1), scaled to cap height 698, side bearings 60, advance 745. Weights 100-500 use the regular source glyph, 600-700 the bold source glyph (both sources share one outline, so the sign does not change weight).

Install for Figma: macOS Font Book > drag the 16 .ttf files in. Then restart Figma. Family names in Figma: "Bawazek Sans" and "Bawazek Sans Arabic".
Web / mocks: woff2/ folder.
Licences: OFL-IBM-Plex.txt, OFL-Saudi-Riyal-Font.txt.
Build script: tools/fonts/add_riyal.py (fontTools).
